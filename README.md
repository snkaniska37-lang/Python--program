About the Project

Welcome to my Python Programs repository!

This repository contains simple Python programs developed as part of my programming practice and learning journey. These programs help me understand basic Python concepts and improve my logical thinking and problem-solving skills.

Programs Included

1. Calculator.py – A simple calculator program that performs basic arithmetic operations.
2. Fibonacci series.py – A program to generate the Fibonacci series using Python.

Technologies Used

- Python
- Basic Arithmetic Operations
- Loops
- Conditional Statements
- Functions

How to Run

1. Open the project folder.

2. Run the Python file:

python Calculator.py

To run the Fibonacci program:

python "Fibonacci series.py"
